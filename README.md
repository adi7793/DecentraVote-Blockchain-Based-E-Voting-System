# DecentraVote — Blockchain Based E-Voting System

DecentraVote is a secure and decentralized blockchain-based e-voting platform built using Ethereum smart contracts. The project aims to provide transparent, tamper-proof, and secure digital voting using blockchain technology.

---

## Features

- Secure voter authentication
- MetaMask wallet integration
- One person one vote system
- Tamper-proof blockchain voting
- Real-time vote counting
- Admin-controlled election management
- Smart contract based vote storage
- Responsive user interface

---

## Installation

### Clone Repository

```bash
git clone https://github.com/adi7793/DecentraVote-Blockchain-Based-E-Voting-System.git
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

### Backend Setup

```bash
cd server
npm install
npm run dev
```

### Blockchain Setup

```bash
cd blockchain
npm install
npx hardhat compile
```
